# 2048

**2048 - Chloé Faillie & Charlotte Germe - 2026**

## Description

2048 est un jeu de réflexion addictif où le but est de combiner des cases ayant la même valeur afin d’atteindre la tuile 2048.

À chaque déplacement, une nouvelle case apparaît. Réfléchissez bien à vos mouvements pour éviter de bloquer la grille !

---

##  Lancer le projet

### ▶️ 1. Lancer la borne sur ordinateur

sh lancerBorne.sh

### 2. Lancer le jeu

- Utiliser les flèches du clavier pour naviguer dans le menu
- Appuyer sur F pour sélectionner le jeu

---

##  Commandes

### Dans le menu :
- Flèche haut / bas : naviguer
- F : valider

### Dans le jeu :
- Flèches : déplacer les tuiles
- F : valider (menu)
- Y : quitter le jeu

---

## Objectif

Fusionner les tuiles pour atteindre 204 !
